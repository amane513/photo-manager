# 0005: 主HDDとSMB共有の整備

作成日: 2026-09-11  
状態: 未着手

## 目的

Ubuntuに常時接続する4TB主HDDを写真・動画の正本として安全に利用できるようにする。MacからSMB経由でアクセスでき、未マウント時にローカルSSDへ誤って保存しない状態にする。

## 対象範囲

- 主HDDを `/mnt/camera_archive` に固定マウントする。
- 写真・動画の保存用ディレクトリと、コピーに必要な権限を設定する。
- MacからSMBで接続し、読み書きできることを確認する。
- 未マウント時にコピー先として使用できないことを確認する。

Immichの導入、実データの本格的な取り込み、第2 HDDへのバックアップはこのプランの対象外とする。

## 前提

- 主HDDはUbuntuに常時接続する4TB HDDである。
- 正本のルートは `/mnt/camera_archive` のみとする。
- Macからの通常の取り込みは、SDカードからSMB経由でこのルートへコピーする。
- SMBの共有範囲は写真ライブラリに限定し、Immichには後続プランで読み取り専用として提供する。

## 実施手順

- [ ] 主HDDのデバイス、ファイルシステム、UUID、容量を確認する。
- [ ] `/mnt/camera_archive` への固定マウントを設定し、再起動後も同じパスで利用できることを確認する。
- [ ] マウント先の所有者・権限を設定し、写真保存用のアカウントだけが書き込めるようにする。
- [ ] Samba共有を設定し、Macから固定の共有名で接続できることを確認する。
- [ ] Macからテストファイルを作成・読み出し・削除し、Ubuntu側でも結果を確認する。
- [ ] 主HDDを安全にアンマウントした状態で、`/mnt/camera_archive` へ書き込めないことを確認する。確認後は再マウントする。
- [ ] 実際のマウント情報、共有名、利用アカウント、確認結果を `validation.md` に記録する。

## 完了条件

- 主HDDが再起動後も `/mnt/camera_archive` にマウントされる。
- MacからSMB経由で写真ライブラリへ読み書きできる。
- 主HDDが未マウントの場合、コピー先として利用できず、SSDへの誤書き込みを防げる。
- 設定値と確認結果が記録され、0006のコピーCLIから保存先として利用できる。
