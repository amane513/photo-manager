作成日: 2026-09-13

更新日: 2026-09-13

状態: 完了（文書改訂）

## 目的

0009の日常運用検証で取り込んだ実データを全件検証に利用し、その後にImmichの導入・表示確認を行ってから、原本と実際のImmich DBを第2 HDDへバックアップする順序へロードマップを変更する。

## 変更内容

- 従来の0013（全件の欠損・内容一致検証）を0010へ再採番した。
- 従来の0010（第2 HDDへのバックアップ・原本復元）を0013へ再採番した。
- 0011（Immich導入）と0012（表示・DB復元）のIDは維持した。
- 推奨順を `0009 → 0010 → 0011 → 0012 → 0013` とした。
- 0010では0009で取り込んだ実データと保持中のコピー元を全件照合する。
- 0011・0012の間はコピー元を保持し、0013で原本とImmich DB・設定のバックアップおよび復元を確認する。
- コピー元の実削除は、0010の全件検証と0013の第2 HDDバックアップが完了した後とした。
- 正本、セットアップ手順、既存プランの参照IDを新しい採番へ合わせた。

未着手の0010・0013には変更時点でプランフォルダが存在しなかったため、既存フォルダの移動は発生していない。予定フォルダ名をそれぞれ `0010_transfer-automation`、`0013_backup-workflow` とした。
