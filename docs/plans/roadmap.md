# プランロードマップ

プラン番号は実施順の目安ではなく識別子である。将来プランのフォルダと `plan.md` は、着手時に作成する。

|---|---|---|---|

## 今後作成するプラン

### 導入に必要

| ID | 予定フォルダ | 概要 | 前提 |
|---|---|---|---|
| 0003 | `0003_media-workflow-validation` | RAW+JPEG、XMP、Live Photo、動画を少数使い、Macでの取り込み・選別・現像・削除手順を検証する | なし |
| 0004 | `0004_amazon-photos-validation` | JPEG、HEIC、ARWのアップロード・再取得、動画除外、ローカル削除時の挙動を検証する | 0003 |
| 0005 | `0005_primary-storage-setup` | Ubuntuへ主HDDを固定マウントし、ディレクトリ、権限、Mac向けSMB共有を構築する | 0002 |
| 0006 | `0006_manual-archive-workflow` | Macから主HDD、Amazon Photosへ保存する一連の手作業を確立し、日常チェックリストを実地検証する | 0003、0004、0005 |
| 0007 | `0007_backup-workflow` | 第2 HDDへのバックアップ方式、Immich DBの保存方法、頻度、検証、復元手順を確立する | 0002、0005 |
| 0008 | `0008_immich-deployment` | Ubuntu内蔵SSDへImmichをCPU構成で導入し、主HDDをread-onlyのExternal Libraryとして登録する | 0005、0007 |
| 0009 | `0009_immich-media-validation` | ARW除外、JPEG、HEIC、Live Photo、動画、現像済みJPEG、DB復元を実データで検証する | 0008 |

0002～0009を初期導入の必須範囲とする。0003と0004は0002と並行して進められるが、0006以降は前段の検証結果を反映してから着手する。

### 運用後に必要性を判断

| 仮ID | 予定フォルダ | 作成条件 | 概要 |
|---|---|---|---|
| 0010 | `0010_transfer-automation` | 手動運用を数回行い、Macから主HDDへのコピーが定型化した場合 | 再実行可能なコピー、ファイル数・容量・チェックサム検証を自動化する |
| 0011 | `0011_backup-automation` | 0007の手動バックアップ方式が安定した場合 | 第2 HDDの接続検知、バックアップ、DBダンプ、結果通知を自動化する |
| 0012 | `0012_media-pair-validation` | RAW/JPEG/XMPまたはLive Photoの組管理で漏れや誤削除が発生する場合 | 対応ファイルの欠落検出と安全な削除補助を実装する |
| 0013 | `0013_filename-normalization` | ファイル名衝突や検索性が継続的な問題になった場合 | dry-runを備えた一括リネーム規則を設計・実装する |
| 0014 | `0014_immich-gpu-acceleration` | CPU構成が安定し、機械学習または動画変換の高速化が必要な場合 | RTX 4060 Tiを使った機械学習と動画変換を段階導入する |
| 0015 | `0015_family-sharing-review` | 管理基盤が安定し、共有方法を見直す段階になった場合 | みてねとImmich等を小規模比較し、祖父母の移行可否を判断する |
| 0016 | `0016_offsite-video-backup` | 動画の重要度・容量が増え、同一拠点2コピーのリスクを受容できなくなった場合 | 有料クラウドまたは別拠点HDDによる動画のオフサイト保護を設計する |
| 0017 | `0017_google-photos-retirement` | Google Photosの全件を主HDD・第2 HDDへ保存し、Immichでの閲覧と復元を確認した後 | Google Photosの写真・動画を段階的に削除し、削除記録と最終確認を行う |

この区分のIDは一覧上の仮予約である。先に別の変更が必要になった場合は、未着手プランの番号を見直してからフォルダを作成する。

## 推奨する着手順

```text
0002 容量測定 ───────────────┬─> 0005 主HDD・SMB構築 ─┐
                              │                        ├─> 0006 手動保存フロー
0003 メディア操作検証 ─> 0004 Amazon検証 ───────────┘
                              │
0002 + 0005 ─> 0007 バックアップ ─> 0008 Immich導入 ─> 0009 メディア検証
                                                                     │
                                                                     └─> 条件付きプラン
```

初期導入では、自動化プランへ進む前に `0006_manual-archive-workflow` を複数回実施し、実際の操作と例外を確認する。
