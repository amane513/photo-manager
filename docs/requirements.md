カメラで撮影したデータを管理・閲覧する環境を構築したい。
どのような構成、環境にするのが良いか提案してください。必要に応じてサブエージェントを立ち上げて既存ツールの仕様を調査してください。

## 前提

- バックアップ先はHDD（4TB）とAmazon Photosを想定。HDDには画像と動画両方、Amazon Photosには画像のみをバックアップ
- カメラはSony α7cii
- スマホ（iPhone13）で撮影した画像・動画もバックアップしたい
- Macbook Airを作業用PCとして使用。まずはMac上で不要な写真を削除、必要に応じて現像してからHDD、Amazon Photosにバックアップする流れにしたい（不要な写真はバックアップさせたくない）。
- JPGとRAWの両方をバックアップしたい。基本的にJPG撮って出しだが、重要な行事などは現像をMacで実施したい。
- Ubuntu PC（デスクトップ、常時稼働）でImmichサーバーを構築したい。理由は、Amazon PhotosにJPGとRAWを両方バックアップすると、閲覧時に両方が表示されて見づらいため。Immichの様々な機能にも興味がある。
- 子供の写真が主な用途。現状祖父母向けに「みてね」というアプリで画像、動画を公開している。より良い方法があればツールを乗り換えることも選択肢（利便性と、祖父母の乗り換えコストの天秤）。
