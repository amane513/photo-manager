# ドキュメント

このディレクトリには、写真・動画管理環境の要件、現在の提案、変更計画、検討履歴を保存する。

## 現在の正本

- [requirements.md](requirements.md): 実現したいことと前提条件
- [proposal.md](proposal.md): 現在採用している構成と運用の提案

要件を変更した場合は、必要に応じて提案との整合も確認する。実装方法だけを変更する場合は、要件を変更せず、提案または変更プランへ反映する。

## 変更プラン

[plans/](plans/) には、リポジトリに対する変更の目的、範囲、手順、完了条件を変更単位で記録する。

## アーカイブ

[archive/](archive/) には、現在の正本ではない検討案や過去の資料を保存する。意思決定の経緯を確認するための資料であり、現在の方針を判断するときは上記の正本を参照する。
