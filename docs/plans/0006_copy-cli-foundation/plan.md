# 0006: コピーCLI基盤の構築

作成日: 2026-09-11

更新日: 2026-09-11

状態: 計画中（具体要件を順次確定する）

## 目的

SDカードまたはMac上の写真・動画を、MacまたはUbuntuの主HDDへ安全に配置するコピーCLIを構築する。日常の取り込みはCLIの実行と結果要約の確認で終えられ、利用者は衝突・失敗・未処理などの例外だけに対応できる状態を目指す。

最初から全仕様を固定せず、代表的な利用シナリオと実データによる確認を通して具体要件を順次決める。ただし、コピー元の保持、無断上書きの禁止、失敗を成功として扱わないこと、主HDD未マウント時の誤書き込み防止は、実装方式によらない前提とする。

## 背景

[requirements.md](../../requirements.md) と [proposal.md](../../proposal.md) では、次の3経路を共通のコピー処理で扱う方針としている。

```text
経路a: SD ─> SMB上の主HDD
経路b: SD ─> MacのPhotoWork
経路c: MacのPhotoWork ─> SMB上の主HDD
```

iPhoneからの機器取得にはmacOSのイメージキャプチャを使用し、取得後の `PhotoWork` からの配置に本CLIを使用する。CLIの処理中核は表示や引数処理から分離し、0014でGUIを追加するときにも利用できる形にする。

## 進め方

要件の具体化と実装を次の順で進める。

1. 代表的な正常系について、利用者が実行するコマンド、入力、配置結果、画面上の要約を具体例で決める。
2. 代表ファイルと異常系を使い、対象列挙、配置、衝突、失敗、再実行の振る舞いを決める。
3. 操作方法と安全要件を満たす実装言語、配布方法、コード配置、共通APIの境界を決める。
4. 明示年月で動作する最小版を実装し、自動テストとローカル試験を行う。
5. 最小版をMacとSMB上の隔離した試験先で実行し、0007の基本確認を開始できる状態にする。
6. 実際のメディアで得た知見を反映し、撮影年月の自動分類、内容一致によるスキップ、再実行、定型設定を追加する。
7. 自動テストと実機試験の結果を記録し、新しいMacで再構築できる手順とスクリプトを整える。

仕様上の重要な判断は必要に応じて `decisions.md` に、テストと実機確認の結果は `validation.md` に記録する。確定していない事項を推測で完了扱いにしない。

## 対象範囲

### 第1段階: 最小版

- SD、Mac上のディレクトリ、SMB上の主HDDをコピー元またはコピー先として扱う。
- コピー対象を再帰的に列挙し、処理予定を確認できるようにする。
- 利用者が年月と機器種別を明示し、`YYYY/YYYY-MM/camera/` または `YYYY/YYYY-MM/smartphone/` へ配置する。
- Macから主HDDへコピーする場合は、既存の年月・機器別の相対配置を維持できるようにする。
- dry-runを提供し、ファイルやディレクトリを変更せずに処理予定と例外を確認できるようにする。
- コピー元を変更または削除しない。
- 既存ファイルを上書きせず、最小版では同名候補を衝突として報告する。
- 主HDDを保存先とする場合は、期待するボリュームがマウントされ、書き込み可能であることを開始前に確認する。
- コピー中は一時ファイルを使用し、完了後に最終名へ切り替える。失敗時の一時ファイルを完成済みとして扱わない。
- 同名衝突や個別ファイルの失敗があっても、継続可能なファイルは処理し、部分完了として区別する。
- 継続不能な保存先切断などを検出した場合は中断し、成功として扱わない。
- 対象、コピー済み、衝突、失敗、未処理を構造化した結果として返し、短い要約と詳細ログを生成する。
- CLIから独立した共通処理APIを用意する。ただし、HTTP APIや常駐サービスは導入しない。

最小版の実装が完了した時点で、0007の代表メディアを使った配置・閲覧確認を開始する。第2段階の完了を0007開始の前提にしない。

### 第2段階: 直後の改善

- 写真・動画の撮影日時を取得し、通常は撮影年月へ自動分類する。
- 撮影年月を判定できないファイルを黙って推測せず、未処理または要確認として報告する。
- 日時不明のファイルを、利用者が年月を明示して再実行できるようにする。
- RAW/JPEG/XMPとHEIC/MOVなど、同じ撮影に属するファイルが別月へ分断されない配置規則を決めて実装する。
- 同名候補の内容を比較し、同一と確認できた場合だけスキップする。名前とサイズだけでは同一と判断しない。
- 内容が異なる同名ファイルは上書きせず、衝突として報告する。衝突時の改名は自動化せず、対象を確認して別途行う。
- 部分失敗や中断の後に再実行し、コピー済みファイルを壊さず未完了分を処理できるようにする。
- コピー先や機器種別など、日常的に繰り返す定型値を安全に再利用できるようにする。
- Macから主HDDへコピーする場合は、ファイルの撮影日時や更新日時で再分類せず、既存の相対配置を維持する。

## 要件具体化で決める事項

以下は実装前または該当機能への着手前に、具体例を確認して決める。

### 操作と設定

- 3経路それぞれのコマンド形式と必須引数
- コピー元・コピー先・年月・機器種別の指定方法
- 定型設定の保存場所、形式、優先順位
- dry-run、通常実行、再実行の操作方法
- 対話入力を必要とするか、非対話実行だけにするか

### 対象ファイルと配置

- SDの `DCIM/` と `PRIVATE/` から列挙する範囲
- 対応する拡張子と、大文字・小文字の扱い
- 未知の形式、隠しファイル、メタデータファイルの扱い
- RAW/JPEG/XMPとHEIC/MOVを同じ撮影として扱う規則
- 複数の日時情報がある場合の優先順位とタイムゾーンの扱い
- 同じ組の中で日時情報が食い違う場合の扱い

### 安全性と結果

- 主HDDを識別する方法とSMB切断の検出方法
- 一時ファイルの命名、配置、残存時の再試行方法
- 個別失敗時に継続できる条件と、全体を中断する条件
- 正常終了、部分完了、実行不能を表す終了コード
- 画面上の要約、構造化結果、詳細ログの形式と保存先
- ログへローカルパスなどをどこまで記録するか

### 実装と配布

- 実装言語と依存ライブラリ
- CLIと共通処理APIの責務境界
- ソースコードとテストの配置
- Macへの導入、更新、設定、動作確認の方法
- 新しいMacで同じ状態を再構築するためのスクリプトと手順

## 対象外

- コピー元の自動削除
- HDD上のファイルを保存確定するための追加操作
- イベント名による分類とイベントフォルダ
- 異なる同名ファイルの自動改名または自動上書き
- 既存XMPや現像済みJPEGをHDD上で更新する同期処理
- 全ファイルを対象としたコピー後の件数・容量・チェックサム検証
- RAW/JPEG/XMPまたはLive Photoの全件ペア欠損検出
- Amazon Photos、第2 HDD、Immichへのバックアップ完了確認
- GUI、HTTPサーバー、認証、ジョブDB、常駐サービス

全件のコピー後検証は0013、GUIは0014、ペア欠損検出は必要性が生じた場合の0016で扱う。更新済みXMPや現像済みJPEGをHDDへ戻す操作は0007と0010で扱う。

## 検証方針

自動テストでは、実データに依存しない小さなフィクスチャと一時ディレクトリを使用する。既存の写真ライブラリをテストで変更しない。日時メタデータや組ファイルの確認に実データが必要な場合も、コピーした少数の代表サンプルを隔離した試験先で使用する。

最低限、次を確認する。

| ID | 段階 | 確認すること |
|---|---|---|
| C01 | 最小版 | 明示年月と機器種別に従ってファイルを配置できる |
| C02 | 最小版 | dry-runではコピー先を変更しない |
| C03 | 最小版 | コピー元を変更または削除しない |
| C04 | 最小版 | 既存の同名ファイルを上書きせず衝突として報告する |
| C05 | 最小版 | 主HDDの未マウントまたはSMB切断時に誤った保存先へ書き込まない |
| C06 | 最小版 | 個別失敗と継続不能な失敗を区別し、失敗を成功扱いしない |
| C07 | 最小版 | コピー途中のファイルを最終名の完成ファイルとして残さない |
| C08 | 最小版 | 結果要約、構造化結果、詳細ログの内容が対応する |
| C09 | 改善 | 複数月のファイルを撮影年月へ分類できる |
| C10 | 改善 | 日時不明を報告し、明示年月で再実行できる |
| C11 | 改善 | 対応ファイルを別月へ分断しない |
| C12 | 改善 | 内容が同じ同名候補だけをスキップする |
| C13 | 改善 | 内容が異なる同名候補を上書きしない |
| C14 | 改善 | 部分失敗や中断の後に安全に再実行できる |
| C15 | 改善 | Macから主HDDへのコピーで既存の相対配置を維持する |

SMB切断、実際のSD構造、メディアの撮影日時、macOS上の導入は実機で確認する。自動化できない確認は手順と実測結果を残す。

## 中間完了条件

第1段階は、次をすべて満たした時点で完了とする。

- 明示年月を使用して3経路の配置付きコピーを実行できる。
- dry-run、コピー元保持、上書き禁止、マウント確認、一時ファイル処理が動作する。
- コピー済み、衝突、失敗、未処理を区別した要約とログを取得できる。
- 主要な安全性を自動テストし、MacとSMB上の隔離した試験先でも確認している。
- 最小版の利用手順と既知の制約が記録され、0007の基本確認を開始できる。

## 完了条件

- 第1段階の中間完了条件を満たしている。
- 撮影年月の自動分類、日時不明の報告、明示年月での再実行ができる。

- 同名候補は内容一致を確認した場合だけスキップし、内容が異なる場合は上書きせず衝突として報告する。
